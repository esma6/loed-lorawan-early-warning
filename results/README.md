# Reported results

This directory contains compact, machine-readable tables and publication
figures generated by the analysis scripts. Prediction-level files and large
window-level intermediates are intentionally excluded from version control;
they are regenerated locally by the documented pipeline.

Subdirectories retain the experiment names used by the scripts and manuscript:

- `results_crc_ablation`: reliability-history ablations.
- `results_statistical_validation`: confidence intervals and paired tests.
- `results_window_duration`: temporal-resolution sensitivity.
- `results_probability_calibration`: calibration summaries and diagrams.
- `results_gateway_reporting`: per-gateway summaries and figures.
- `results_streaming_replay`: alarm and latency summaries.
- `results_physical_precursors`: observable precursor analyses.
- `results_temporal_models`: sequence-model comparisons.

All CSV files are UTF-8 encoded. Values reported in the manuscript are derived
from these compact outputs or from prediction-level artifacts regenerated by
the corresponding script.
