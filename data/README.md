# Data acquisition

The analyses use the public **LoED: The LoRaWAN at the Edge Dataset**:

- Dataset DOI: https://doi.org/10.5281/zenodo.4121430
- Dataset article DOI: https://doi.org/10.1145/3419016.3431491

Download the full archive and save it as:

```text
data/LoED_LoRaWAN_at_edge_dataset.zip
```

`loed_experiments.py` extracts the archive into `data/LoED_full_extracted/`.
Both locations are ignored by Git because the source archive is approximately
380 MB and remains governed by its original distribution terms. No gateway
identifiers are added or modified by this repository.
